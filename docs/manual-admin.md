# Manual rapido de administrador

1. Abrir `/login`.
2. Ingresar con una cuenta de rol `admin`.
3. Abrir `/admin` para consultar el resumen y las pestañas de usuarios, solicitudes, recolecciones y reglas.
4. Para operar una bandeja, usar los enlaces de coordinacion. El admin puede acceder a ambos flujos.
5. Salir con el boton `Salir` para revocar la sesion local.

Las cuentas incluidas son exclusivamente de demostracion y deben rotarse antes de cualquier uso real.
