1. Abrir la portada y explicar que el ciudadano pide por WhatsApp.
2. Simular texto organico con direccion y horario.
3. Mostrar la solicitud en la bandeja de huerteros.
4. Ingresar como `coord_huerteros`, programar y mostrar la notificacion simulada.
5. Registrar peso, material y cualidades; mostrar puntos y estado recolectada.
6. Repetir con reciclable para demostrar aislamiento de colectivos.
7. Ingresar como `admin` y mostrar el tablero consolidado.
8. Mostrar `/docs/estado-final.md` para explicar que WhatsApp real requiere credenciales Meta.
