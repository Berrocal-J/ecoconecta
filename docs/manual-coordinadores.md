# Manual rapido de coordinadores

1. Abrir `/login`.
2. Usar `coord_huerteros` para organicos o `coord_recicladores` para reciclables.
3. Filtrar la bandeja por estado.
4. Programar solo cuando existan colectivo, persona y fecha/hora.
5. Al finalizar, registrar material, peso y cualidades.
6. El sistema cambia a recolectada, calcula puntos y notifica por WhatsApp.

El backend impide que un coordinador opere el flujo del otro.
